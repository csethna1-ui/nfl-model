# Experiment 008 — Methodology

**Frozen protocol:** `protocol.md` (2026-09-29, locked before any candidate
validation results).

## Research question
V1 predicts home margin by direct scalar regression (ELO + EPA-linear + GBM,
0.4/0.5/0.1). Six feature-expansion experiments and the V2 component ladder
all failed to beat it. Experiment 008 tests whether the *target* is the
binding constraint: NFL margin is generated by two scoring processes
(home score, away score), and directly estimating E[margin] may discard
information.

## Two sub-questions (evaluated separately)
- **Question A:** does the architecture improve expected-margin prediction?
- **Question B:** does the architecture better represent uncertainty?
A model improving only calibration is a distributional improvement, NOT a
superior margin predictor.

## Phase 1 — literature (see `literature_review.md`, `architecture_comparison.md`)
Ten architecture families surveyed (A–J). Key statistical facts constraining
the experiment:
1. For MAE, the optimal point forecast is the conditional **median**, not mean.
2. Heteroskedasticity alone **cannot** improve a point forecast.
3. Margin = home − away exactly; two-process models lose no information by
   construction — the question is only whether they estimate location better.
Selected (≤3): **008-A** separate home/away score regressions,
**008-B** linear quantile regression (median as point forecast),
**008-C** heteroskedastic margin model (Question B only).

## Phase 2 — variance diagnostic (see `variance_diagnostic.md`)
Walk-forward within 2021–2022: corr(predicted |resid|, actual |resid|) = 0.055;
in-sample R² = 0.021; predicted-σ log score worse than constant σ.
**Verdict: WEAK.** Complex variance models de-emphasized; 008-C is a
Question-B test only.
